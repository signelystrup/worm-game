**stat:** permanent default effects that apply to every character. (MAX_HEALTH, CURRENT_HEALTH, VISION, ACTIONS )\

**effect:** Temporary status effects which boost or debuff a character. (eg. BURNING, POISONED, INVINCIBLE) 
Weapons and items can inflict effects.

**talent:** Permanent, passive abilities besides default stats. (eg. TOUGH, RICH, NIGHT_VISION)



**level:** skill-level of a character. When levelling up, the character gets a bonus-stat and a new talent. 

**stage:** a room/floor/map in the world. the game consists of multiple stages. 


**actions:** how many actions a character can do in a turn. Actions are: move 1 tile, attack, use item, interact (pick up item, unlock door)

**turn:** 1 round. the time a character has to perform its actions.
